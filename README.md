# Apex Auto Care - Responsive Small Business Website

A multi-page website built for a fictional auto repair shop demonstrating semantic HTML5 structure, CSS custom styling, and responsive layout hierarchy.

## Key Features
- **Semantic HTML5:** `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` elements across all pages.
- **Custom CSS Styling:** External stylesheet controlling layout, typography, navigation UI, and color palette.
- **Structured Data:** Tables, definition lists, ordered/unordered lists, and sub-page layouts.

## Tech Stack
- HTML5
- CSS3
